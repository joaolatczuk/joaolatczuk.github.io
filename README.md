## 💻 Sobre o Projeto

Este site foi projetado para demonstrar na prática minhas habilidades em desenvolvimento front-end, priorizando usabilidade, acessibilidade, performance e design consistente.

### ✨ Principais Funcionalidades
* **Tema Dinâmico (Light / Dark Mode):** Alternância de cores com paleta personalizada inspirada em tons verde-floresta e grafite.
* **Scroll Snap & Transições:** Navegação fluida bloco a bloco com animações de entrada via `IntersectionObserver`.
* **Linha do Tempo Interativa:** Seção dedicada para exibir trajetória acadêmica, experiências corporativas e vivências internacionais.
* **Formulário de Contato Direto:** Integração via FormSubmit para envio direto de mensagens por e-mail.
* **Design 100% Responsivo:** Interface adaptada para smartphones, tablets e desktops.
