## 💻 Sobre o Projeto

Este repositório contém o código-fonte do meu portfólio pessoal. O objetivo principal da aplicação é apresentar minhas soluções técnicas, stack de desenvolvimento e projetos práticos, aliando alta performance, SEO otimizado e uma experiência de navegação fluida em qualquer dispositivo.

### ✨ Funcionalidades em Destaque
* **Tema Dinâmico (Light / Dark Mode):** Alternância instantânea de tema com paleta personalizada em tons verde-floresta e grafite.
* **Navegação & Scroll Snap:** Transições suaves bloco a bloco acompanhadas de animações com `IntersectionObserver`.
* **Linha do Tempo Profissional:** Seção detalhada com histórico acadêmico, experiências profissionais e vivências práticas.
* **Formulário de Contato:** Envio direto de mensagens via integração com FormSubmit.
* **Design 100% Responsivo:** Layout flexível otimizado para mobile, tablet e desktop.
* **Boas Práticas de SEO:** Controle de indexação configurado via `robots.txt` e marcação semântica.

---

## 🚀 Tecnologias & Bibliotecas

* **Linguagens & Estilização:** HTML5 Semântico, CSS3 Moderno (Grid, Flexbox, Variáveis CSS, Scroll Snap) e JavaScript (ES6+).
* **Bibliotecas Front-end:** [Typed.js](https://mattboldt.github.io/typed.js/) (efeito de digitação interativo) e ícones via Boxicons / Remix Icon.
* **Deploy & Domínio:** GitHub Pages com suporte a domínio personalizado via `CNAME`.
